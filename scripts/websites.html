คู่มือสำหรับทีม Backend — หน้า Websites

จัดการเว็บไซต์ listing อสังหาริมทรัพย์ที่พบ — บันทึก URL, จัด-label, ค้นหาด้วย Google Search ผ่าน Serper API

1) Database — ตารางที่เกี่ยวข้อง

TableColumnsหมายเหตุ
saved_websites id (uuid PK), url (text UNIQUE), label (text default 'none'), created_at เก็บ URL ที่บันทึกไว้; label = none | agency | landlord | marketing
search_config id (uuid PK), config_key (text UNIQUE), config_value (jsonb), created_at, updated_at เก็บ config แบบ key-value; seed data: excluded_domains, search_language, search_keywords

2) API — Saved Websites (CRUD)

MethodURLBodyResponse
GET/api/saved-websites—[{ id, url, label, created_at }] (sort created_at desc)
POST/api/saved-websites{ url, label? }201 row / 409 duplicate
PATCH/api/saved-websites?id={ url? } or { label? }200 row / 404
DELETE/api/saved-websites?id=—200 { ok: true }

Duplicate protection: DB constraint UNIQUE (url) + backend check query ก่อน insert → 409 ถ้าซ้ำ

3) API — Find Websites (Serper Search)

MethodURLBodyResponse
POST/api/find-websites{ queries: ["keyword1", "keyword2"] }{ websites: ["https://..."], count }

Serper API request format:

POST https://google.serper.dev/search
Headers: { "X-API-KEY": "<SERPER_API_KEY>", "Content-Type": "application/json" }
Body (array): [
  { "q": "warehouse factory for rent", "hl": "th" },
  { "q": "โกดังโรงงานให้เช่า",      "hl": "th" }
]

hl = host language code ของ Google (ค่าจาก search_config key search_language, default "th") — กำหนดภาษา/region ของผลลัพธ์ Google Search

Serper API response format:

// Response เป็น array (1 element ต่อ 1 query)
[
  {
    "searchParameters": { "q": "warehouse factory for rent", "hl": "th", ... },
    "organic": [
      { "title": "...", "link": "https://example.com/listing/123", "snippet": "..." },
      { "title": "...", "link": "https://other.com/page", "snippet": "..." }
    ]
  },
  { "organic": [...] }
]

Workflow ภายใน:

  1. โหลด config จาก search_config (excluded_domains, search_language)
  2. แปลง queries → Serper body: queries.map(q => ({ q, hl: searchLanguage })) — ส่งเป็น array (batch request, 1 call ครอบทุก keyword)
  3. เรียก POST https://google.serper.dev/search ด้วย X-API-KEY header
  4. Response อาจเป็น array หรือ object เดียว → normalize เป็น array (Array.isArray(serperData) ? serperData : [serperData])
  5. Loop ทุก result → ดึง organic[].link → แปลงเป็น root domain ด้วย new URL(link).origin (ตัด path ทิ้ง เหลือแค่ https://example.com)
  6. กรอง domain ที่อยู่ใน excluded_domains (subdomain match: hostname === d || hostname.endsWith('.' + d))
  7. Deduplicate origins ด้วย Set → sort alphabetical → return { websites: [...], count }

Excluded domains (default): thaiindustrialproperty.com, facebook.com, youtube.com

Error handling: Serper ไม่ OK → return 502 พร้อม error text (ตัด 300 ตัวอักษร); ไม่มี SERPER_API_KEY → return 500

4) API — Search Config

MethodURLBodyResponse
GET/api/search-config—{ excluded_domains: [...], search_language: "th", search_keywords: [...] }
PATCH/api/search-config{ search_keywords: [...] }200 { ok: true } (upsert per key)

5) Frontend Flow — Find Website

  1. กด "Find Website" → openFindModal() → โหลด keywords จาก GET /api/search-config
  2. กด "Search" → searchWebsites(): POST /api/find-websites ด้วย keywords ทั้งหมด
  3. Loop ผลลัพธ์ → POST /api/saved-websites ทีละ URL (auto-save ทั้งหมด)
  4. URL ซ้ำ (409) → ข้าม, นับเป็น skipped
  5. แสดง toast: "X saved, Y skipped (already exist)" → refresh ตาราง
