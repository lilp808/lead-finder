คู่มือสำหรับทีม Backend — หน้า Login

หน้าแรกก่อนเข้า Dashboard — หน้าเว็บอื่น ๆ จะ redirect มาที่นี่ถ้ายังไม่ได้ล็อกอิน

API ที่ใช้

MethodURLBodyสำเร็จผิดพลาด
POST/api/login{ "username", "password" }200 { "ok": true } + Set-Cookie fp_session401 { "error": "invalid_credentials" }

สิ่งที่ Backend ต้องทำ

  • ตรวจ username / password เทียบกับ env LOGIN_USERNAME / LOGIN_PASSWORD
  • ออก cookie fp_session (HttpOnly, Path=/, SameSite=Lax, อายุ 7 วัน)
  • ทุกหน้าเว็บต้องตรวจ cookie นี้ก่อนให้ข้อมูล; ถ้าไม่มี → redirect ไป /login
FindProperty
