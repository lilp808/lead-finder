คู่มือสำหรับทีม Backend — หน้า Result Leads

แสดงเฉพาะ lead ที่ "สมบูรณ์ พร้อมส่ง Agent" — คือ snapshot จากตาราง result_leads

API

GET /api/result-leads?search=&agent_team=&source_platform=&page=1&limit=12

Paramความหมาย
searchค้นหา contains ใน address, post_url, source_name, ai_summary, province
agent_teamA / B / C; none = ไม่มีทีม (NULL)
source_platformfacebook

Response: { results: [], total, page, totalPages }

ฟิลด์ในการ์ด

image_urls, property_type, agent_team, rent_price, sale_price, pricing_area_sqm / building_area_sqm / land_area_sqm, listing_status, province, district, sub_district, address, ai_summary, google_maps_url, post_url, source_platform, source_name, lead_id

ปุ่ม View / Share

  • ใช้ lead_id (ชี้กลับไปที่ตาราง leads) → GET /api/leads/:lead_id เพื่อดึงรายละเอียดเต็ม
  • ถ้าไม่มี lead_id → แสดง "No source lead for this result"

เบื้องหลังที่ Backend ต้องรู้

  • result_leads เกิดจาก workflow: lead ที่ข้อมูลครบ (มี SQM, province+district+sub_district, มีรูป, มีราคา, มี agent_team) → snapshot เข้า result_leads (key เฉพาะ lead_id)
  • มีระบบ dedup + merge: หา candidate (ตำแหน่งเดียวกัน + SQM ตรง) → AI เทียบรูป → ถ้าเป็นที่เดียวกัน confidence ≥ 0.7 → merge
  • เมื่อแก้ google_maps_url ที่หน้า Leads ต้อง sync มาที่ result_leads ด้วย

Collect ทำงานอย่างไร (โดยละเอียด)

  1. กดปุ่ม Collect Now (หน้า Config) → GET /api/collect?sourceId=<id> ไล่ทีละ active source
  2. Backend (src/routes/collect.js): อ่าน source_configs (active=true) → จัดกลุ่มตาม platform → getCollector() + ตรวจ isAvailable() → collector.collect() → step summary → saveRunLog() ลง lead_logs
  3. Facebook collector (src/collectors/facebook.js): สั่ง Apify รัน apify/facebook-groups-scraper (proxy residential) → poll ทุก 3 วิ (งบ 55 วิ) → mapApifyItem() แปลงฟิลด์ → processItems() ทีละ 5 posts
  4. ต่อ post: (1) Dedup — post_url ซ้ำ หรือ raw_post_text เท่ากัน + จำนวนรูปเท่ากัน; (2) AI extract (extractProperty) — confidence < 0.3 → drop; (3) โหลดรูป max 10 → อัปโหลด bucket lead-images; (4) extractGoogleMapsUrl(); (5) assignAgentTeam(); (6) insertLead(); (7) processLeadForResult()
  5. AI (src/lib/groq.js): system prompt (prompts/extract-property.md) + ข้อความ post (ตัด 4000 ตัวอักษร) → typhoon (default) หรือ groq (JSON mode), temp 0.1, retry 3 → AI คืน JSON → computePrices() คำนวณราคา per_sqm → raw × pricing_area_sqm
  6. Prompt (extract-property.md): "You extract industrial property listing information from Facebook posts." → คืน JSON เท่านั้น, กฎ per-sqm ≠ ราคารวม, schema 25+ ฟิลด์, ไม่ใช่อสังหาฯ → confidence 0
  7. Result workflow (src/workflow/result-leads.js): isComplete() → snapshot result_leads → หา duplicate → vision (Groq qwen/qwen3.6-27b, prompt compare-properties.md, ≤2 รูป/ฝั่ง) → merge เก็บโพสต์ที่สมบูรณ์กว่า
